# Атлас систем

С телефона: https://andrewantoshkin.github.io/sbhealth/

Главный экран персонального здоровья: интерактивная 3D-модель человека, 13 систем организма, цвет показывает уровень риска. Нажатие на орган открывает подробности. Работает как PWA, открывается с телефона и с десктопа.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc + vite build
```

## Что внутри

**Атлас** — стартовый экран.
- 3D-тело (three.js через @react-three/fiber). 13 систем окрашены по уровню риска: зелёный, жёлтый, оранжевый, красный. Тап по органу или по карточке в ленте подводит камеру и показывает детали.
- На телефоне снизу лента карточек систем и шторка с подробностями (показатели, что это значит, запись к врачу). На десктопе то же самое боковой панелью.
- Индекс здоровья в углу сцены открывает шторку с расчётом: из чего складывается число, вклад систем, динамика.
- Пока загружается настоящая модель, виден готовый кадр тела, поэтому первый экран не пустой.

**Сводка** — что важно сейчас: индекс, зоны внимания, следующий шаг, подборка статей.

**Врачи** — каталог специалистов и профиль врача. Запись предлагает ближайшее свободное время, приём можно перенести или отменить.

**Сообщения** — переписка с врачами; запись создаёт диалог.

**Ассистент** — объясняет показатели атласа простыми словами и отвечает действиями: показать орган, записаться к врачу, открыть статью. Открывается со Сводки, из карточки органа и из Сообщений. Ответы собираются из данных приложения (`src/assistant.ts`), модели за ним нет; на тревожные симптомы он советует звонить 103.

**Профиль**, **Полезное** (короткие статьи со ссылками в атлас), **уведомления**.

## Как устроено

- Роутинг на хэшах (`src/App.tsx`), переходы между экранами через View Transition API. Тяжёлый экран атласа с 3D грузится отдельным чанком, а сервис-воркер регистрируется после его готовности, чтобы не мешать первой отрисовке.
- 3D-сцена в `src/scene` изолирована от интерфейса: экраны передают ей выбранную систему, высоту шторки и сигнал сброса камеры.
- Модель: `public/models/anatomy.glb` (около 1,5 МБ). Собирается скриптом `scripts/prepare-anatomy.mjs` из открытого атласа органов: меши сгруппированы в 13 систем, мелочь убрана, геометрия упрощена и сжата.
- Состояние (записи, переписки, уведомления, прочитанное) лежит в `src/store.ts` и сохраняется в localStorage. Бэкенда нет.
- Данные о системах, врачах и статьях лежат в `src/data`. Показатели, врачи и тексты придуманы для сценария и не являются медицинской информацией.
- Стили: `styles.css` → `theme.css` → `screens.css` → `flow.css` → `start.css` → `design.css`. Дизайн-система — в `design.css`: белый фон, один акцент — почти чёрный `#111317` — для действий и выбора, цвета риска только для данных о здоровье, крупные жирные заголовки, одна шапка у всех вкладок (`TabHeader`), липкая верхняя панель и классический таб-бар внизу, касание от 44 px.
- Русская типографика: неразрывные пробелы после предлогов вставляет `src/typo.ts`, заголовки и абзацы балансируются через `text-wrap`.
- Доступность: управление с клавиатуры, видимый фокус, `prefers-reduced-motion`, подписи у иконок-кнопок, модальные окна с ловушкой фокуса.
