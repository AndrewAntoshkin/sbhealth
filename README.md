# Атлас систем

С телефона: https://andrewantoshkin.github.io/sbhealth/

Демо главного экрана персонального здоровья: интерактивная 3D-модель человека, 13 систем организма, цвет показывает уровень риска.

Открывается с телефона как PWA. Данные на экране выдуманы и не являются медицинским заключением.

Анатомия — упрощённая производная [Human Reference Atlas](https://humanatlas.io/3d-reference-library), мужской референс v1.10, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Подробности в `public/models/NOTICE.txt`.

```bash
npm install
npm run dev
```
